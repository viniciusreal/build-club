# build club

Comunidade **grátis** no WhatsApp para jovens founders e empreendedores que querem crescer juntos.

Gente nova construindo negócio, startup ou projeto, trocando o que funciona de verdade.

**[Entrar no build club](https://chat.whatsapp.com/IWI1cGYRbVm88Yx2ksm5dZ?mode=gi_t)**

## Como funciona

| Dia | O que rola |
|---|---|
| Segunda | cada um posta a meta da semana |
| Quarta | uma pergunta pra todo mundo trocar |
| Sexta | placar de quem bateu a meta e o único dia de divulgar o seu projeto |

E aos poucos: calls mensais, convidados, desafios de 30 dias e encontros presenciais.
